# Product Constitution

## Product Name

SovereignGrid

## Mission

Provide a local-first, offline-capable, open-source spreadsheet workspace suitable for organizations of any size.

## Core Principles

- Open Source
- Local First
- Offline First
- No Telemetry
- No Mandatory Cloud
- Vendor Neutral
- Organization Neutral
- Security By Design

## Non Goals

SovereignGrid is not:

- Microsoft Excel
- Google Sheets
- ERP
- CMMS
- EAM
- Government System
- Healthcare System

## Truthfulness Rule

The project must never claim:

- Certification
- Compliance
- Approval
- Readiness
- Compatibility

unless evidence exists.

## Data Policy

Public repository contains synthetic data only.

No real organizations.

No real users.

No real assets.

No real locations.

## Architecture Principle

Modular Monolith.

WPF.

MVVM.

Plugin-oriented extensions.
