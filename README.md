# SovereignGrid

SovereignGrid is a local-first, offline-capable spreadsheet workspace for asset management, reporting and workbook-oriented operations.

## Goals

- Local-first
- Offline capable
- No telemetry
- No cloud dependency
- Organization-neutral
- Open source

## Status

Current Phase:
Repository Foundation

Implemented:
- Repository structure

Planned:
- Policy Engine
- WPF Shell
- Workbook Engine
- Storage Layer
- Asset Workspace
- Import / Export
- Plugin SDK

Unsupported:
- Production deployment claims
- Government certification claims
- Healthcare certification claims
- Full Microsoft Excel compatibility claims
